# 试片与连续性

## 试片最小要求

选择故事中 15–25 秒、3–5 个真正连续的镜头，必须同时覆盖：

- 脸部近景；
- 人物转头或转身；
- 人与物的接触、抓取或递交；
- 中文对白和自然停顿；
- 至少一个明确切镜。

只测空镜、单人站立或同构图微动，不能证明整集可生产。

## 每镜记录

```text
镜头ID / 剧本场次：
叙事用途 / 新信息：
计划长度 / 对白实测长度 / 停顿：
景别 / 机位 / 视线 / 轴线：
人物、服装、地点、道具、参考版本：
起始状态：站位、朝向、持物、接触点
主要动作：触发 → 接触或转折 → 落点
结束状态：
声音：说话人、逐字台词、环境、音效、发声窗口
下一镜关系：普通切镜 / 同镜延长 / 时空跳变
真实起始参考：
生成后可用区间：
缺陷与修复决定：
```

## 六条连续性线

| 检查线 | 必须保持或解释 | 常见修复 |
|---|---|---|
| 人物身份 | 脸型、发型、体态、服装结构、配件、声音 | 回到固定参考资产修镜，不能只补一句“同一个人” |
| 空间 | 轴线、视线、左右站位、进出方向、物件位置 | 调整机位，或用有叙事职责的空间重建镜头 |
| 动作 | 起势、接触、承重、落点、动作方向 | 减少同时动作、拆镜，消除滑步和物体穿手 |
| 状态 | 伤势、湿污、持物手、门开关、天气时间 | 对照上一镜实际可用结束状态与资产变体 |
| 声音 | 音色、空间感、环境声、完整字音、停顿 | 跨镜音床、统一处理、重配异常句，音画共同复核 |
| 剧情 | 已知信息、动机、关系、承诺、伏笔、因果 | 回改剧本，不能用漂亮空镜遮盖逻辑缺口 |

切镜可以改变构图，但人物相对关系、视线、动作状态和对白必须接得上。人物自身左右与观众画面左右必须分别表述。

## 普通切镜和同镜续接

普通切镜要为下一镜独立构图，以共享身份与场景资产保持一致。把上一镜尾帧机械地作为下一镜首帧，常会得到错误的同构图、僵硬运动或累积畸变。

同镜延长才使用实际上一段视频和真实尾帧，并接住动作速度、未完成动作、光线与声音。分镜计划或生成前设想的尾帧不能替代真实输入。

## 20 秒检查例

场景：黄昏亭内，人物甲在画面左侧，人物乙在右侧；桌面中央有铜铃，主光从画面左侧进入，摄影机保持在人物连线同侧。

| 时间 | 画面 | 验收点 |
|---|---|---|
| 0–5秒 | 双人中景，乙右手把铃推到桌心并松手 | 接触声完整，左右手不跳变 |
| 5–10秒 | 甲近景，先看画面右下的铃，再抬眼看画面右侧 | 中文台词说完并留自然停顿，视线正确 |
| 10–15秒 | 手部特写，甲右手抓稳铃柄后抬起 | 接触、承重、抬起均可见，无穿插 |
| 15–20秒 | 乙反应近景，视线朝画面左侧 | 甲在画外仍持铃，声音空间连续 |

## 试片通过证据

同时保留可连续播放的视频、实际参考版本、模型与参数、任务 ID、真实费用、可用区间和问题记录。通过要求：脸不明显漂移、接触可信、切镜后方向和状态一致、对白无明显口型错位。任何一项仅凭首尾抽帧都不能判定通过。
