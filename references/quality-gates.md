# 成片质量门槛

自动检查能证明文件、引用、时长、编码和响度等技术事实，不能证明故事好看、表演自然或角色连续。所有阻断和重大缺陷必须关闭，不能用总分抵消。

| 类别 | 通过条件 | 必要证据 |
|---|---|---|
| 叙事 | 因果和台词完整，观众理解核心变化 | 全片正常速度观看，问题定位到秒 |
| 角色 | 关键镜和相邻镜无明显身份、服装、音色漂移 | 定妆对照与连续播放 |
| 表演 | 情绪反应可见，转头与接触合理 | 完整镜头观看，必要时慢放定位 |
| 画面 | 无明显变形、穿插、闪烁、融化或无因跳变 | 动态观看加首中尾与切点抽帧 |
| 口型 | 主要发声与收口自然，无明显嘴停声不停 | 按实际对白逐句回看，正面近景从严 |
| 节奏 | 无凑时长僵停、误删反应或重复表演 | 预演与成片对照 |
| 声音 | 字音完整、无爆音、底声不断裂、音乐不盖词 | 回听、响度与真峰值测量 |
| 字幕 | 台词准确、时序对应、手机端可读、不压脸 | 剧本文字核对和实际视频检查 |
| 文件 | 完整解码，画幅、帧率、音轨符合交付规格 | ffprobe/FFmpeg 检测及整片播放 |

## 审查顺序

1. 用技术工具检查解码、时长、帧率、画幅、音轨、黑帧、静音和响度。
2. 逐镜检查身份、动作、状态、口型和明显生成缺陷。
3. 在手机显示尺寸下，以正常速度不暂停地完整观看，判断叙事、节奏和情绪。
4. 回到问题秒点做慢放、抽帧或音轨对照，定位责任环节。
5. 修复后重新走受影响的检查；素材替换后必须复核相关剪点、字幕和声音。

## 问题记录

```text
问题编号：
位置：镜头ID / 成片秒数
证据：实际看见或听见的问题
严重程度：阻断 / 重大 / 轻微
影响：理解 / 识别 / 连续性 / 技术交付
责任环节：剧本 / 资产 / 分镜 / 提示词 / 生成 / 后期
修复范围：
复核结果与方式：
```

## 不能误判为通过

- 文件生成成功，不代表动作和表演合格。
- 第一帧像角色，不代表转头后的侧脸一致。
- 字幕对齐音频，不代表嘴型与声音一致。
- 引用或脚本检查通过，不代表故事因果和镜头方向正确。

- `EP001_zh.srt`：中文字幕；
- 对白、音乐、环境和音效分轨；
- 实际使用的参考资产和版本说明；
- 剧本、视觉设定、图片提示词、分镜、视频提示词；
- 剪辑单、生成批次记录、问题与修复记录。
