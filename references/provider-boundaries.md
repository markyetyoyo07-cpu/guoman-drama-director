# 生成服务与工具边界

## 投产前核验

对实际账号和当前版本核对：模型 ID、计费单位、参考图数量、首尾帧、视频续接、音频驱动、分辨率、时长、并发、内容限制和任务恢复方式。不要从旧文档、营销名或工具安装状态推断服务能力。

“配音可生成”不等于“口型已解决”。选择独立配音时，先验证口型服务或视频模型能驱动三维角色；选择模型原生对白时，先验证中文字音、音色、表演和口型，再锁定可用音轨。

## 提交与恢复

提交前记录输入资产版本和预算。收到任务 ID 后立即保存。若轮询、下载或客户端连接中断：

1. 查询并恢复原任务；
2. 核对供应商是否已经计费并生成结果；
3. 只有确认原任务不可恢复时才重新提交；
4. 在批次记录中说明重投原因。

这可防止因网络故障重复烧预算。

## 续接限制

普通切镜不需要视频续接；下一镜应独立构图。真正延长同一镜头，必须确认服务接受上一段真实视频或真实尾帧，以及所需音频条件。如果当前适配器不能绑定续接视频、多镜组或特定参考类型，转到供应商已验证的界面完成，再把原始输出导回项目；不要伪造已支持的能力。

## 本地生成

本地工作流只能在模型权重、节点、显存峰值、速度和样本质量经过实测后标为“可用”。先用短、低分辨率样本验证，再决定是否进入试片。存在软件目录或显卡不代表工作流就绪。

## 后期工具

字幕、合成和技术检测也需要小样验证。确认 FFmpeg/ffprobe、中文字体、字幕滤镜、音轨和最终渲染入口实际可用。Remotion、HyperFrames、剪辑软件或其他合成方案可以共存，但同一版本成片只应有一个最终时间线和导出入口。
